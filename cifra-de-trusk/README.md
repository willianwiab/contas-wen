# 🔐 Cifra de Trusk

O código secreto inventado pelo Jojo: cada letra vira a **tecla de trás** no teclado.

- **Criar código:** anda pra trás: troca cada letra pela tecla que fica à esquerda dela (M vira N, L vira K, P vira O, 8 vira 7).
- **Decifrar:** faz o contrário, andando uma tecla pra frente (pra direita).
- Q, A, Z e 1 são as primeiras da fileira e não têm tecla atrás, então ficam iguais na hora de criar.
- P, L, M e 0 não têm tecla na frente, então ficam iguais na hora de decifrar.
- Usa as fileiras do teclado: `1234567890`, `qwertyuiop`, `asdfghjkl`, `zxcvbnm`.
- Acentos saem antes (é vira e, ç vira c), maiúsculas continuam maiúsculas, espaço e emoji ficam iguais.
- Teclado na tela que mostra pra onde cada letra anda. Botão de copiar pra mandar no WhatsApp.
- Funciona sem internet e instala como aplicativo.

Exemplo: `oi, tudo bem` → `iu, rysi vwn`, e `78` → `67`
