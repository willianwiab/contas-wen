# 🔐 Cifra de Trusk

O código secreto inventado pelo Jojo: cada letra vira a **tecla do lado** no teclado.

- **Criar código:** troca cada letra pela tecla que fica à direita dela (Q vira W, A vira S, 7 vira 8).
- **Decifrar:** faz o contrário, andando uma tecla pra trás (pra esquerda).
- P, L, M e 0 são as últimas da fileira e não têm tecla na frente, então ficam iguais.
- Pra decifrar, todas andam uma tecla pra trás, até essas: M vira N, L vira K, P vira O e 0 vira 9.
- Usa as fileiras do teclado: `1234567890`, `qwertyuiop`, `asdfghjkl`, `zxcvbnm`.
- Acentos saem antes (é vira e, ç vira c), maiúsculas continuam maiúsculas, espaço e emoji ficam iguais.
- Teclado na tela que mostra pra onde cada letra anda. Botão de copiar pra mandar no WhatsApp.
- Funciona sem internet e instala como aplicativo.

Exemplo: `qual e o meu nome` → `wisl r p mri mpmr`
