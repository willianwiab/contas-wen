Cifra de Trusk

O código secreto do Jojo: cada letra vira a tecla de trás no teclado. Só quem sabe o segredo consegue ler!

Aperta uma tecla pra ver pra onde ela anda.

Como funciona a Cifra de Trusk

  1. 🔊 Aperta Falar pra ouvir a mensagem, ou Soletrar pra ouvir letra por letra.
  2. Pra criar o código, anda pra trás: troca cada letra pela tecla que fica à esquerda dela. M vira N, L vira K, P vira O.
  3. As primeiras teclas da fileira (Q, A, Z e 1) não têm tecla atrás, então ficam iguais.
  4. Pra decifrar, faz o contrário: anda pra frente, trocando pela tecla que fica à direita.
oi, tudo bem → iu, rysi vwn
78 → 67 … e 67 decifrado é 78
